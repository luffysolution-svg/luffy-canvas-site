# 本地 Agent 接入规划

本地 Agent 的目标是让 Codex、Claude Code、WorkBuddy 和其他标准 MCP 客户端在不暴露本机凭据的前提下操作当前网页画布。

## 目标架构

```text
线上或本地 Luffy Canvas
          |
  安全配对 + HTTP/SSE
          |
 Luffy Canvas Agent
    |            |
AgentAdapter   luffy-canvas MCP
    |            |
Codex/Claude   标准 MCP 客户端
```

自有 npm 包为 `@luffysolution/canvas-agent`，MCP Server ID 为 `luffy-canvas`，新配置目录为 `~/.luffy-canvas/`。

## Provider 范围

- Codex 侧边栏保留 app-server 会话、附件、流式事件和 token usage 体验。
- Claude Code 侧边栏按本机 CLI 的真实能力实现，不伪造不支持的历史恢复。
- WorkBuddy 仅作为外部标准 MCP 客户端，不在网页侧边栏内启动。
- Provider 的 session ID、状态和日志相互隔离。

## 权限边界

MCP 支持 `readonly`、`editor`、`generator`、`assets`、`full` 五个 Profile。Profile 负责工具暴露和输入级过滤，网页负责实际写操作审批。

以下操作默认需要网页确认：

- 删除或修改现有节点；
- 图片、视频、音频和文本生成；
- 素材添加或覆盖；
- 附件落画布和批量画布操作。

读取画布、选区和快照不要求确认。自动连接只建立连接，不能关闭审批。

## 安全连接

- pairing code 一次性且短期有效；
- session token 可过期、可撤销；
- token 不进入 URL、Referrer、日志和永久本地存储；
- Agent 默认只监听 `127.0.0.1`；
- Origin 在配对时授权；
- 旧永久 token 只提供一个版本的弃用兼容。

## 迁移

新目录首次启动时读取旧 `~/.infinite-canvas/`，迁移 URL、端口、Origin、工作空间和会话索引等非敏感数据。旧目录不删除，也不再写入。

旧 `infinite-canvas` 插件、MCP ID、Claude 工具前缀和 `@basketikun/canvas-agent` 命令由迁移文档引导移除，不再作为默认路径。
