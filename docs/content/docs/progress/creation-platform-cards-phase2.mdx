# AI 创作审核台 Phase 2

Phase 2 在 Phase 1 的人工方案审核、提示词版本和候选生成链路上增加平台画板与多页卡片。项目仍保存在浏览器本地，图片 Blob 写入 IndexedDB；AI API Key 仍保存在浏览器本地，并由前端直接请求所配置的 OpenAI 兼容接口。

## 核心流程

```text
文章 / Markdown
→ 本地结构化拆成 1–10 页（默认 6 页）
→ 页面排序、增删、标题正文和布局编辑
→ 使用已批准提示词生成首张风格锚点
→ 其余页面携带同一风格锚点批量生成
→ 逐页审核或只重绘问题页
→ 按一个或多个平台精确合成 PNG
→ 单页导出、批量 ZIP、保存资产或批量插入 Canvas
```

单页重绘只更新目标页。其他成功页的图片、审核状态和生成溯源不会被清空；旧图片继续保存在项目生成历史中。

## 集中式平台规格

| 预设 | 尺寸 | 比例 | 安全区重点 |
| --- | ---: | ---: | --- |
| 微信公众号头条封面 | 900 × 383 | 900:383 | 标题和关键主体避免贴边 |
| 小红书图文 | 1080 × 1440 | 3:4 | 避让上下裁切，系列标题基线一致 |
| X 帖子横图 | 1200 × 675 | 16:9 | 兼顾时间线缩略预览 |
| B站投稿封面 | 1146 × 717 | 16:10 | 缩略图下仍保持主体和标题清晰 |
| 抖音视频封面 | 1080 × 1920 | 9:16 | 避让右侧互动区与底部账号、导航区 |

平台尺寸、比例、安全边距和注意事项都来自同一预设数据库。项目只保存 canonical preset ID，分析、生图、预览、导出和 Canvas 溯源共用同一解析入口。

## 页面与风格数据

- `CreationProject.cardDeck` 保存目标平台、活动平台、统一风格 ID、模型参数、风格锚点和有序页面。
- 每页保存稳定 ID、标题、正文、独立布局、内容修订号、生成状态、审核状态、当前图片、图片历史和页级生成记录。
- 页面生成记录包含 batch、风格、提示词版本、模型、平台规格、参考页和参考图；最终合成图另记录页面、规格和底图来源。
- 页面图片继续归档到项目级 `generatedImages`，因此 IndexedDB 恢复、图片清理、资产和 Canvas 链路不需要第二套存储。

## 平台画板与安全区

编辑器中的平台画板使用真实宽高比，并让预览与最终 PNG 共用同一套布局几何。安全区是画板上方独立的只读 DOM 覆盖层，带 `pointer-events: none`，不会写入图片 Blob，也不会成为导出渲染指令。

准确标题和正文由浏览器在最终合成阶段绘制。生图提示词要求模型只生成无文字视觉底图并预留低干扰区域，避免把模型乱码当作交付文字。

## 多平台导出与 Canvas

- 同一套页面内容可以选择微信、小红书、X、B站和抖音中的一个或多个目标规格；横竖画板会按布局重新计算文字区域并对视觉底图执行等比 cover crop。
- 单平台单页直接导出 PNG；多页或多平台导出 ZIP，平台分目录保存，并附带包含尺寸、页码、布局、底图、提示词和模型溯源的 `manifest.json`。
- 保存资产或插入 Canvas 时使用已经合成准确文字的最终平台图片。
- 多页 Canvas 插入使用持久化命令批次，按页码正序消费，并围绕当前视区中心从左到右排开；刷新中断后仍可继续消费且不会重复节点。

## 本阶段边界

- 不实现科研模式、科研事实 QA、Python/R 数据图或 Agent 自动化入口。
- 多平台适配复用同一份页面内容和视觉底图，当前不自动改写各平台的发布文案。
- 生成请求仍受所配置服务的浏览器 CORS、模型比例能力和远程图片有效期限制；远程结果无法本地化时不能执行最终合成、资产保存或 Canvas 插入。
- 本文记录当前版本待人工确认的实现；用户确认前不更新正式功能说明。
