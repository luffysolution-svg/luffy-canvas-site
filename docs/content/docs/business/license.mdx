# 开源协议

Luffy Canvas 采用 GNU Affero General Public License v3.0 only（`AGPL-3.0-only`）开源协议。你可以在遵守协议条款的前提下使用、复制、修改、分发和商业使用本项目。

## 项目初衷

Luffy Canvas 保持开源，希望让更多人可以查看和修改代码，不被固定 API 渠道限制，接入自己的 API 与模型渠道，用画布组织提示词、参考图、素材和生成结果，搭建适合自己的 AI 创作工作流。

本仓库基于上游项目 [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas) 修改；上游及各贡献者的版权仍归其各自权利人所有，具体归属见仓库 `NOTICE`。

## 使用建议

如果你只是本地学习、研究或自用，可以直接按开源协议使用。

如果你计划将项目用于商业产品、私有化交付、SaaS 服务或长期团队内部系统，建议先确认自己的使用方式是否满足 `AGPL-3.0-only` 的源代码提供、版权与许可证保留等要求。

如果你需要评估其他授权方式、私有化部署支持或定制开发服务，请查看[商务合作](/docs/business/business)。其他授权是否可行取决于相关代码的权利归属与授权范围。



## 需要注意的 AGPL 要求

以下是便于理解的概括，不能替代许可证正文或专业法律意见：

- 分发本程序或其修改版本时，需要按许可证提供对应源代码、许可证文本和必要的版权声明。
- 如果你修改本程序并让用户通过网络与其交互，AGPL 第 13 条要求向这些用户提供获得对应源代码的方式。
- 受 AGPL 覆盖的衍生作品通常需要继续按兼容的 AGPL 条款授权；具体边界取决于实际集成与分发方式。
- 不应移除原项目作者、上游来源、版权和许可证声明，也不能对许可证已授予的权利增加额外限制。
- 项目按现状提供，不附带适销性、特定用途适用性等担保；完整免责条款以 `LICENSE` 为准。

AGPL 不禁止商业使用，但商业使用不会免除许可证义务。对闭源交付、SaaS、插件组合或企业内部部署存在疑问时，请让具备资质的法律顾问结合你的具体方案审查。
