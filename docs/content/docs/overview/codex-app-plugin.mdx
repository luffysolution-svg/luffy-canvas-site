# Codex App 插件

当前插件源码位于 `plugins/luffy-canvas/`，插件 ID 和 MCP Server ID 均为 `luffy-canvas`。完整使用说明见 [Codex 集成](/docs/integrations/codex)。

## 从仓库安装

```bash
git clone https://github.com/luffysolution-svg/luffy-canvas-site.git
cd luffy-canvas-site
cd canvas-agent
npm ci
npm run build
cd ..
codex plugin marketplace add "$(pwd)"
codex plugin add luffy-canvas@luffy-canvas-local
```

Windows PowerShell 将 `"$(pwd)"` 换成 `"$PWD"`。安装或更新后新建 Codex 任务。

## 从旧插件迁移

```bash
codex plugin remove infinite-canvas
codex mcp remove infinite-canvas
codex plugin marketplace remove luffy-canvas-site-local
```

旧项不存在时忽略对应提示，然后重新注册当前仓库 marketplace。

## 本地源码调试

需要调试当前仓库中的 Agent 源码时，先构建本仓库：

```bash
cd canvas-agent
npm ci
npm test
npm run build
codex mcp add luffy-canvas -- node /absolute/path/to/luffy-canvas-site/canvas-agent/dist/index.js mcp --profile editor
node dist/index.js
```

普通 `node dist/index.js` 提供网页连接；带 `mcp` 的进程提供 stdio 工具。日常使用请改用已发布的 `@luffysolution/canvas-agent@0.2.0`。

## 安全连接

打开 `https://luffy-canvas-site.vercel.app/canvas?mode=new` 后，在网页配对界面输入短期 pairing code。不要把 pairing code 或 session token 放进 URL；自动连接也不会关闭写操作确认。
