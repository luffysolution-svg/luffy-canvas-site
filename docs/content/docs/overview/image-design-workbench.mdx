# 生图工作台设计系统

生图工作台把创作输入拆成四个相互独立的层次：

1. 用户提示词决定具体内容和必须保留的信息。
2. 平台预设决定比例、请求尺寸、安全区、避让区和平台展示偏好。
3. 设计 Skill 决定内容组织、视觉语言、文字策略和单图或系列工作流。
4. 当前模型设置决定渠道、质量、数量、参考图和模型实际支持的尺寸。

功能全部在浏览器中运行，不依赖 Agent、MCP、Codex/Claude Skill Runtime、本地脚本或新增后端。图片仍通过项目现有 `requestImageBatch` 请求链生成。

## 设计 Skill

| Skill             | 主要用途                           | 工作流                                 |
| ----------------- | ---------------------------------- | -------------------------------------- |
| 无设计 Skill      | 已有完整 Prompt、自由生成          | 保持原生单图流程                       |
| 文章封面图        | 公众号封面、缩略图、文章头图       | 类型、预设、配色、渲染、文字和画幅组合 |
| 小红书 / 社交图卡 | 知识卡、清单、教程、社交系列       | 1–10 张拆卡、顺序编辑、首图锚点        |
| 专业信息图        | 数据、流程、矩阵、框架和高密度内容 | 结构化编辑、布局 × 风格组合、数据忠实  |
| 文章配图          | Markdown、文章和长文本             | 章节分析、插图位置与逐图计划           |
| 漫画与故事分镜    | 单页、多页、四格、条漫             | 角色/场景视觉圣经、分镜与逐项 Prompt   |
| 技术图解与关系图  | 流程、架构、层级、时间线和网络     | 结构化关系语义，调用图片模型生成位图   |

封面、小红书、信息图、文章插图和漫画的注册选项与预设基于 Baoyu Skills 转译。固定来源、提交和许可证见仓库中的 [`docs/third-party/baoyu-skills.md`](https://github.com/luffysolution-svg/luffy-canvas-site/blob/main/docs/third-party/baoyu-skills.md)。

预设选择器支持搜索、平台筛选、收藏和最近使用。自定义预设可以新增、编辑、删除，并以 JSON 导入或导出；内置预设不会被导入内容覆盖。

自定义预设入口位于平台预设选择器的“自定义”。可以配置生图尺寸、平台参考尺寸、比例、安全区、避让区、主体/标题位置、文字密度、Prompt 规则和禁止项。导出的结构为 `{ "version": 1, "presets": [...] }`；导入时会完整校验字段、尺寸、比例和方向，同 id 的自定义预设会被更新，任何无效项都会使整次导入失败。当前图片请求统一输出 PNG。

`sourceLevel` 表示规则来源级别：

- `official`：平台公开规范可直接支持的字段；
- `industry-recommended`：常见创作或发布实践；
- `product-default`：Luffy Canvas 为稳定生成选择的产品默认；
- `custom`：用户自行维护。

`verifiedAt` 是预设最近一次核对规则时记录的元数据，不表示平台规范永久不变。发布重要内容前仍应核对平台最新要求。

## 尺寸与比例

平台预设中的 `generationSize` 直接进入模型能力解析和图片请求。正常流程是让模型直接生成目标比例，而不是先生成再裁剪。

- 模型支持目标尺寸时，直接请求该尺寸。
- 模型支持同一比例的其他尺寸时，使用同一比例兼容尺寸。
- 模型只有固定比例或尺寸档位时，界面显示实际映射并要求确认。
- 系统不默认裁剪、不拉伸，也不静默改变比例。
- `targetPlatformSize` 只是上传和发布参考尺寸，不代表系统必须进行后处理。
- 结果卡显示模型实际生成的像素；远程结果在保存到本地后可补充实际尺寸。

尺寸解析复用 `web/src/services/api/image.ts` 的 OpenAI、OpenAI Compatible、Gemini、Qwen 和自定义脚本能力。兼容渠道无法预先证明尺寸支持时会标记为“未验证”，而不是假装精确支持。

## 推荐与确认

“智能推荐”有两层：

- 本地确定性规则：没有文本模型、请求失败或 JSON 非法时始终可用。
- 文本模型推荐：复用现有文本模型渠道，只接受注册表中的 Skill、平台和 option id。

推荐仅提供默认值，并显示可公开的简短依据。用户显式选择的参数和平台尺寸强约束不会被覆盖。引导模式会先显示推荐和确认；快速模式会在点击生成时直接编译，但比例兼容映射仍需要用户确认。

## 最终 Prompt

纯函数 Prompt Compiler 按稳定顺序组合：

1. 用户输入；
2. 内容目标；
3. 结构化内容；
4. 布局、构图、风格、配色、光线和文字；
5. 平台安全区与避让区；
6. 参考图角色；
7. 实际请求尺寸与比例；
8. 禁止项。

用户可以查看编译分段、编辑最终 Prompt、恢复系统版本、重新编译、复制，或替换原始提示词。生成请求使用最终 Prompt，并把系统版、手动覆盖状态、编译器版本和全部参数保存到可复现快照。

## 系列、文章和分镜

系列计划支持新增、删除、排序和编辑。每项保存独立 Prompt；失败项可以单独重试，不会重新生成已经成功的项。

启用首图锚点后：

- 图片 1 先生成；
- 模型支持参考图且未达到上限时，图片 2 以后追加图片 1 作为 `series-anchor`；
- 用户原始参考图不会被覆盖；
- 不支持参考图或已经达到上限时，后续 Prompt 注入 visual bible；
- 用户可以在偏好中关闭锚点链。

文章模式只把当前章节摘要、插图目的、视觉说明和必须保留的事实送入对应图片 Prompt，不会把整篇文章无差别重复到每一张图。信息图识别内容过载时会建议拆分，而不是擅自删除数字或单位。

## 参考图角色

每张参考图可以标记为：

`direct`、`subject`、`identity`、`style`、`palette`、`composition`、`layout`、`product`、`character` 或 `series-anchor`。

未标记角色时仍按原有参考图方式提交，不额外改写无 Skill 的原始 Prompt。Qwen 继续遵守最多 3 张、单张不超过 10 MB 和允许格式限制；参考图优化只创建请求用派生图，不修改原图。

工作台只会在能力明确时自动启用系列参考锚点：Gemini、Qwen、GPT Image、ChatGPT Image 和 DALL·E 2 可进入参考图流程，DALL·E 3 不支持参考图；无法识别能力的兼容渠道或自定义脚本不会被假定为支持。不同中转服务仍可能施加更严格的尺寸、格式或参考图限制，实际请求以渠道返回为准。

## 记录、资产与本地数据

生成记录保存原始 Prompt、最终 Prompt、Skill、平台、尺寸映射、推荐、结构化计划、逐项状态和可复现快照。点击记录会恢复完整工作台状态。旧版记录会经过容错归一化，不会因为缺少新字段导致页面崩溃。

工作台偏好、生成记录、图片和资产主要保存在浏览器 localforage / IndexedDB 中。目前不提供云端自动同步。AI API Key 仍保存在浏览器本地，并由前端直连用户配置的接口；设计系统不会把 Key 发送到额外服务。

远程图片链接可能过期，也可能因 CORS 无法下载。工作台会先保留可见的远程结果；“保存到本地”、加入资产或加入参考图是否成功取决于远程地址和同源代理配置。
